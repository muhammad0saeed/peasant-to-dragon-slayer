# Peasant to Dragon Slayer

A retro 2D action platformer that runs in the browser. This is the playable prototype of **Act 1-1: Burning Farms**.

**Play it:** https://muhammad0saeed.github.io/peasant-to-dragon-slayer/

Everything in the game is drawn and synthesised in code: characters, tiles, backgrounds, font, sound effects and music. It is one HTML file with no libraries, images or audio files.

## Controls

| Action | Keyboard | Gamepad |
| --- | --- | --- |
| Walk | Arrows or WASD | D-pad or left stick |
| Run (uses stamina) | Shift or C | B or right shoulder |
| Jump (hold for higher) | Z or Space | A |
| Jab | X or J | X |
| Crouch | Down | Down |
| Climb or talk | Up | Up |
| Pause | P or Esc | Start |
| Mute | M | |

## Run it locally

Download `index.html` and open it in a browser. No install or server needed.
